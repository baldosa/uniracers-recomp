Uniracers Web

Runs in your browser on the snesrecomp interpreter. No game is included: pick your own Uniracers (USA) ROM. It stays on your machine; saves and settings are kept in this browser.

Controls

B / AZ / XSelectRight Shift

Gamepads work through the browser. Two players on one keyboard: edit keybinds.ini (desktop builds) — the web build uses the defaults above.
